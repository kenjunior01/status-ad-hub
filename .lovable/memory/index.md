# Project Memory

## Core
WhatsApp Status ad marketplace. Primary green #128C7E, dark mode default.
Currencies: MZN (Metical) and BRL (Real) only. USD as internal base.
Lovable Cloud backend. Mobile-first with fixed bottom nav z-[60].
Mascot: Camaleão (green chameleon) with 8 mood expressions.
Pricing AI compares with Meta Ads & Google Ads costs.
localStorage key: statusads_localization_v2 (v1 purged).
Bottom nav is role-aware: visitor/creator/advertiser/admin menus.
No global transform:translateZ(0) — breaks fixed positioning.
